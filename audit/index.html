    Rules passed.

      Creating a PBIP. In Power BI Desktop, choose File > Save as and pick Power BI project. Turning on the TMDL and PBIR preview options gives the most complete results.

      Scoring. Each area starts at 100. Warnings cost 3 points and info items 1, capped per rule at 12 and 5. Overall is the average of the areas checked.

      Limits. Query speed, model size and data quality need the running model. Use Performance Analyzer, DAX Studio and VertiPaq Analyzer alongside this check.
